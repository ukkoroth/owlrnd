# 6. Data

The things owlrnd stores and how they relate. Names are descriptive; choose your own field types and storage.

| Entity | Belongs to | Key fields | Notes |
| --- | --- | --- | --- |
| Parent | none | name, email, email verified, password (hashed), created at | The customer. Receives all codes. |
| Student | Parent | name, class, username (unique), password (hashed), time zone | No email. |
| Code | Parent, and the student it was requested for (if any) | purpose (verify email, sign in, reset password, change email), code (stored hashed), expires at, tries left, used at | Single use; a new code invalidates earlier unused codes of the same purpose. |
| Session | Parent or Student | device, created at, last seen | Ended by Sign out. |
| Track | Student | name, status (active, paused, goal reached, archived), test date, goal threshold X, goal run length N, goal progress, created at | Subject is part of the name in 0.1. |
| Topic | Track | name, order, added in (which chat), revision only (yes/no) | Found by the AI from the material. |
| Track chat message | Track | author (parent or AI), text, attachments, created at | The conversation that created or extended the track. |
| Attachment | Track chat message | file, type (photo, PDF), extracted text | Textbook pages or syllabus from the parent. |
| Question | Track, Topic | type (multiple choice, short, long), prompt, options, correct option, expected answer, key points, marks, difficulty, created at | A bank per track, generated by the AI. |
| Exam | Student, Track | number in track, created at, started at, submitted at, marked at, score out of 10 | Up to 10 questions. |
| Exam question | Exam, Question | position, page (set at layout time, not stored) | Fixes the paper's order. |
| Answer | Exam question | chosen option or typed text, saved at | Saved as the student works. |
| Mark | Answer | marks awarded, verdict, reason or feedback, marked by (rule or AI) | One per answer. |
| Topic strength | Student, Topic | status (strong, needs work, not tested), recent results | Recomputed after each marked exam. |
| Points event | Student, Exam | kind (finish, correct, improvement, topic strong, perfect, streak), points, created at | Total points = sum; never decreases. |

## Derived values

- **Total points and level:** sum of points events; level from the thresholds in rules §8.
- **Goal progress:** consecutive exams in the track at or above X, newest backwards (rules §3).
- **Activity:** completed exams per day in the student's time zone (rules §9).
- **Suggestions:** computed when the dashboard loads (rules §7).
