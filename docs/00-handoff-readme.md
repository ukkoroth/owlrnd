# owlrnd 0.1 hand-off package

Everything needed to build owlrnd version 0.1.

| Path | What it is |
|---|---|
| `CLAUDE.md` | Instructions for Claude Code: reading order, scope, non-negotiables, build order |
| `docs/` | Product, scope, flows, screens, rules, data, AI, design, roadmap, open decisions |
| `screens/` | A PNG screenshot of every screen, named by its code (for example `2e_…png`) |
| `mockups/` | A static HTML snapshot of every screen, for exact wording and layout |

Screens are 1280px wide, the laptop layout. Screen codes match the "MVP" page of the design canvas.
