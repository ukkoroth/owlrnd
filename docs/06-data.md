# 6. Data

The things owlrnd stores and how they relate. Names are descriptive; choose your own field types and storage.

| Entity | Belongs to | Key fields | Notes |
| --- | --- | --- | --- |
| Parent | none | name, email, email verified, password (hashed), AI allowance override, created at | An account holder. Receives their own and their children's codes. |
| Student (learner) | Parent (parent-managed only) | type (parent-managed, self-managed), name, class, username (parent-managed), email and email verified (self-managed), date of birth, consent, AI allowance override (self-managed), password (hashed), time zone | Parent-managed: no email, signs in with a username. Self-managed (0.2): signs in with their own email and is their own account holder. |
| Parent link *(0.2)* | Parent, Student | kind (manages, consents), status, verification level, given at | "manages" for each parent-managed child; "consents" for an under-18 self-managed learner (M10). |
| Consent request *(0.2)* | Student (cleared if the account is deleted) | parent's name and email, link (stored hashed), link expires at, status (pending, agreed, declined, expired), verification level, progress view, policy version, the parent's current code (hashed, expiry, tries), reminded at, answered at | One open request per learner; a new link ends the earlier one. Kept as audit after a decline. |
| Consent event *(0.2)* | Consent request, Student (both cleared on deletion) | kind (requested, link resent, email changed, reminder sent, code sent, code wrong, code verified, agreed, declined, paused for no answer), detail, at | The audit record of consent. No practice data. |
| Code | Parent and/or the student it was requested for | purpose (verify email, sign in, reset password, change email), code (stored hashed), expires at, tries left, used at | Sent to the account holder. Single use; a new code invalidates earlier unused codes of the same purpose. |
| Session | Parent or Student | device, created at, last seen | Ended by Sign out. |
| Track | Student | name, status (active, paused, goal reached, archived), test date, goal threshold X, goal run length N, goal progress, created at | Subject is part of the name in 0.1. |
| Topic | Track | name, order, added in (which chat), revision only (yes/no) | Found by the AI from the material. |
| Track chat message | Track | author (parent, learner or AI), text, attachments, created at | The conversation that created or extended the track. |
| AI usage | Parent (family) or self-managed learner | purpose, model, tokens, cost, created at | One row per Claude call; sums to the monthly spend and each account holder's allowance. |
| Attachment | Track chat message | file, type (photo, PDF), extracted text | Textbook pages or syllabus from the parent. |
| Question | Track, Topic | type (multiple choice, short, long), prompt, options, correct option, expected answer, key points, marks, difficulty, created at | A bank per track, generated by the AI. |
| Exam | Student, Track | number in track, created at, started at, submitted at, marked at, score out of 10 | Up to 10 questions. |
| Exam question | Exam, Question | position, page (set at layout time, not stored) | Fixes the paper's order. |
| Answer | Exam question | chosen option or typed text, saved at | Saved as the student works. |
| Mark | Answer | marks awarded, verdict, reason or feedback, marked by (rule or AI) | One per answer. |
| Topic strength | Student, Topic | status (strong, needs work, not tested), recent results | Recomputed after each marked exam. |
| Points event | Student, Exam **or** Flashcard session | kind (finish, correct, improvement, topic strong, perfect, streak, flashcards), points, label, created at | Total points = sum; never decreases. Exactly one of exam and flashcard session is set; one award per session. |
| Flashcard *(0.3)* | Track, Topic | front, answer, explanation, source (material or missed question, with the question), box 1–5, due at, created at | The track's deck; at most 200. Goes with the track. |
| Flashcard session *(0.3)* | Student, Track | started at, finished at, cards seen, got it | A few minutes of practice; never changes scores or goals. |
| Flashcard review *(0.3)* | Flashcard session, Flashcard | result (got it, not yet), at | One per card per session; moves the card's box. |

## Derived values

- **Total points and level:** sum of points events; level from the thresholds in rules §8.
- **Goal progress:** consecutive exams in the track at or above X, newest backwards (rules §3).
- **Activity:** completed exams per day in the student's time zone (rules §9).
- **Suggestions:** computed when the dashboard loads (rules §7).
